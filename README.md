# Financial Modeling & Scenario Analysis | Portfolio Project

This repository showcases a **financial performance dashboard** and a **5-year forecast** for a hypothetical tech startup, **NovaTech Solutions**. The project integrates historical actuals with forward-looking projections under multiple scenarios to demonstrate scenario-driven financial analysis.

---

## Project Overview

The model evaluates:

- Revenue growth
- Margin expansion
- Cash flow sustainability  

using **scenario-driven operating assumptions**. This project is part of an **FP&A and financial modeling portfolio**.

### Scenarios Modeled

1. **Base Case**
2. **Best Case**
3. **Worst Case**

---

## Key Outcomes by Scenario

### Base Case
- Revenue growth: mid-to-high teens CAGR  
- EBITDA margin: expands from ~18% to ~40%  
- Net income margin: improves to mid-20% range  
- Operating cash flow: steady generation  

### Best Case
- Revenue growth: high-teens to low-20s CAGR  
- EBITDA margin: expands to ~50%  
- Net income margin: low-30% range  
- Operating cash flow: robust, supporting accelerated reinvestment and strong balance sheet  

### Worst Case
- Revenue growth: low-teens CAGR  
- EBITDA margin: expands gradually to ~40%  
- Net income margin: stabilizes in low-20% range  
- Operating cash flow: positive but tighter, highlighting downside sensitivity  

---

## Key Insights

- Variations in growth and margin assumptions materially impact **profitability**, **cash generation**, and **financial flexibility**.
- Demonstrates the value of scenario analysis in financial planning and decision-making.
